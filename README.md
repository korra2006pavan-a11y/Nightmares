❤️ Milap – Verified Social Networking Platform

Milap is a modern, secure, location-based social networking platform designed to help verified single adults connect, discover nearby people, build meaningful relationships, and communicate safely.

The platform focuses on identity verification, privacy, secure authentication, and trusted community interactions.

⸻

🌐 About the Project

Milap provides a members-only networking experience with verified profiles, email and mobile OTP authentication, selfie verification, private messaging, location-based discovery, and monthly membership access.

Our mission is to make online connections safer, more private, and more meaningful.

🚀 Getting Started

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the Project

cd milap

3. Install Dependencies

npm install

4. Configure Environment Variables

Create a .env.local file in the project root.

Add the environment variables required by your database, authentication, email, SMS and payment verification integrations.

Use .env.example as your configuration template.

Never commit passwords, API keys, database credentials, or private secrets to GitHub.

5. Set Up the Database

Configure your database connection and run the Drizzle migrations using the scripts configured in your project.

6. Start the Development Server

npm run dev

Open:

http://localhost:3000

🌍 Deployment

The application can be deployed using platforms that support Next.js server-side rendering.

Recommended platform:

Vercel: https://vercel.com/

Deployment steps:

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Configure environment variables.
4. Connect the production database.
5. Deploy the application.
6. Configure your custom domain.

Important: This is a dynamic Next.js application. GitHub Pages static hosting is not suitable for the current server-side implementation because it uses database queries, authentication, and dynamic rendering.
